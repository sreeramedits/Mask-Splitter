# Mask-Splitter

#Installation

1. Copy the .jsx file into the After Effects ScriptUI Panels folder.

Mac:
/Applications/Adobe After Effects <VERSION>/Scripts/ScriptUI Panels/

Windows:
C:\Program Files\Adobe\Adobe After Effects <VERSION>\Support Files\Scripts\ScriptUI Panels\

2. Restart After Effects.

3. Open the panel from:
Window → Extensions/ScriptUI Panels → <Panel Name>

4. If required, enable “Allow Scripts to Write Files and Access Network” in After Effects → Settings → Scripting & Expressions.
